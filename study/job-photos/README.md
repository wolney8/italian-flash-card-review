# Photographs for Italian job practice

Use real photographs from identifiable photographers or collections. Each photograph needs a source record that identifies the work shown and permits reuse on the course website. Exclude AI-generated images, reconstructions and images whose provenance or reuse terms are uncertain.

Before adding a photograph, compare the image with the original caption. Save a locally resized copy and record the photographer, source URL, reuse terms, original file, date and archive identifier in `sources.json`. The learner can open the credit and original record from each question.

Use a visible action for the clue. Choose alternatives the scene distinguishes. For example, taking blood pressure shows healthcare work. The source caption identifies this particular worker as a registered nurse, so the other choices are a cook and a teacher. Present both Italian gender forms where appropriate.
